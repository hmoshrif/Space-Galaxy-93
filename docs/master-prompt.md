# أمر الاستدعاء الرئيسي (Systematic Ultra-Pro Master Prompt)

الأمر الممنهج الذي وُلّد منه هذا المنتج — يعرّف الدور، السياق، النجم القطبي،
المبادئ الحاكمة (P1–P8)، بروتوكول التنفيذ المرحلي (Stage-Gate 0→6)،
الأدوار والصلاحيات، الحدود التقنية، وعقد المخرجات.

> النسخة الكاملة محفوظة في محادثة الإنشاء. هذا الملف مرجع موجز للمبادئ الحاكمة المطبَّقة في الكود.

## المبادئ الحاكمة (منفّذة في v1)
- **P1** كل درجة مرتبطة بسلسلة: فجوة ← سبب ← أثر ← توصية ← إجراء ← مسؤول ← موعد ← مؤشر ← دليل إغلاق.
- **P2** تقييم قائم على الأدلة: لا اعتماد آلي دون مراجع بشري.
- **P3** شفافية الحساب: الأوزان ومنطق الاحتساب ظاهرة.
- **P4** ثبات النتائج: تجميد Snapshot + إصدار المعادلة عند الإطلاق.
- **P5** عربي أولاً: RTL حقيقي، `start/end` لا `left/right`.
- **P6** الأمن بالتصميم: فصل مستأجرين، سجل تدقيق، صلاحيات حسب الدور، جاهزية PDPL.
- **P7** الذكاء الاصطناعي مساعد لا حاكم (مؤجَّل لـ v2 مع مراجعة بشرية إلزامية).
- **P8** البساطة قبل الثراء: سؤال واحد، قائمة قابلة للطي، حفظ ظاهر.

## بروتوكول التنفيذ (Stage-Gate)
0. الإطار والاستراتيجية → [`product-brief.md`](product-brief.md)
1. نموذج النضج → [`maturity-model.md`](maturity-model.md) + [`../app/js/model.js`](../app/js/model.js)
2. رحلة المستخدم والشاشات الست → منفّذة في [`../app/js/ui.js`](../app/js/ui.js)
3. بنية البيانات والمعمارية → [`../app/js/store.js`](../app/js/store.js)
4. البناء (v1 MVP) → ✅
5. النتائج التنفيذية → ✅
6. الجودة والاعتماد → اختبار منطقي + تحقّق بصري عبر المتصفح ✅
