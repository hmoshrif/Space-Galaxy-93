# نموذج النضج الأولي — نضج إدارة الاستراتيجية والأداء

> **نموذج واحد فقط في v1** (المرحلة 1). التسلسل: المجال ← القدرة ← السؤال ← معيار المستوى + الدليل.

## سلّم النضج العام (Rubric 1–5)
| المستوى | المعنى |
|---|---|
| 1 | لا توجد ممارسة موثقة أو تطبيق ثابت |
| 2 | ممارسة جزئية أو غير متسقة |
| 3 | ممارسة موثقة ومطبقة في معظم النطاق |
| 4 | ممارسة مقاسة ومراجَعة ومحسّنة |
| 5 | ممارسة متكاملة، تنبؤية، ومثبتة النتائج |

## أنواع التقييم والأوزان الافتراضية
النضج = **30% توثيق + 30% تطبيق + 20% إدراك + 20% نتائج** (قابلة للضبط بشفافية).

- **توثيق (documentation):** وجود السياسات والأدوات والأدلة وجودتها.
- **تطبيق (application):** مدى تطبيق الممارسة فعلياً لا مجرد وجود وثيقة.
- **إدراك (perception):** رأي الموظفين وأصحاب المصلحة (سري).
- **نتائج (results):** إثبات أثر قابل للقياس.

## المجالات الثلاثة
1. **التخطيط الاستراتيجي** — وضوح الاتجاه ومواءمة الأهداف.
2. **مواءمة وقياس الأداء** — ربط المؤشرات ومصداقية القياس.
3. **ثقافة التحسين والتنفيذ** — تحويل النتائج إلى إجراءات مغلقة.

التفاصيل الكاملة للأسئلة والمعايير والأدلة المقبولة مُعرّفة برمجياً في
[`app/js/model.js`](../app/js/model.js) كمصدر واحد للحقيقة (Single Source of Truth).

## قرار معماري حاكم (P4)
عند إطلاق كل تقييم يُجمَّد **Snapshot** من النموذج + **إصدار معادلة الاحتساب**،
فلا تتغير النتائج القديمة عند تعديل الأسئلة أو الأوزان لاحقاً.
