# وثيقة المنتج (Product Brief) — منصة نضج

> **المرحلة 0** من بروتوكول التنفيذ — صفحة واحدة تحكم القرارات.

## القيمة المقترحة
منصة عربية لإدارة **النضج المؤسسي** تحوّل الأدلة وآراء أصحاب المصلحة إلى
**درجات موثوقة** و**خارطة تحسين قابلة للتنفيذ والقياس** — لا مجرد استبيان يعطي رقماً من 1 إلى 5.

## من؟
| السؤال | الإجابة |
|---|---|
| العميل الأول | إدارات الاستراتيجية والأداء + الجهات الاستشارية |
| المستخدم الفعلي | المقيّم، المراجع، مدير التقييم، المدير التنفيذي |
| المشكلة | تقييمات النضج تُدار بـ Excel/استبيانات، بلا أدلة موثّقة، بلا اعتماد، ولا تتحول إلى تنفيذ |
| النتيجة المدفوعة | دورة كاملة: قياس موثّق ← فجوات ← خطة ← متابعة ← إعادة قياس |

## لماذا أفضل من المرجع؟ (5 اختلافات)
1. **أبسط استخداماً** — رحلة موجهة وشاشة سؤال واحد غير مزدحمة.
2. **أقوى إثباتاً** — كل درجة مربوطة بدليل ومراجعة واعتماد.
3. **أكثر شفافية** — الأوزان ومنطق الاحتساب ظاهرة للمستخدم.
4. **أكثر قابلية للتنفيذ** — الفجوات تتحول تلقائياً إلى مبادرات ومهام.
5. **أفضل للسعودية** — عربي أصيل RTL، هجري/ميلادي، جاهزية PDPL.

## النجم القطبي (North Star)
> يستطيع مستخدم حقيقي إتمام: **إنشاء تقييم ← إجابة + أدلة ← اعتماد ← فجوات ← خطة ← نتائج** دون احتكاك.
