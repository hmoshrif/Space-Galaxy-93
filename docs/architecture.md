# البنية المعمارية — مسار الإنتاج (v2)

النسخة الحالية (v1) تُثبت دورة القيمة كاملةً بتخزين محلي بلا خطوة بناء.
هذا المستند يعرّف الترحيل إلى بنية مؤسسية متعددة المستأجرين.

## المكدّس
| الطبقة | التقنية | لماذا |
|---|---|---|
| الواجهة | **Next.js 14 + TypeScript + Tailwind** (App Router, RTL, PWA) | أداء، SSR للتقارير، `start/end` منطقي |
| الخلفية | **NestJS** (API-first, REST/GraphQL موثّق) | وحدات واضحة، حراس صلاحيات |
| قاعدة البيانات | **PostgreSQL + RLS** | فصل مستأجرين قوي — [`schema.sql`](schema.sql) |
| تخزين الأدلة | **Object Storage مشفّر** + روابط تنزيل مؤقتة | سرية الأدلة |
| الهوية | **MFA + SSO/OIDC** (النفاذ الوطني اختيارياً) | متطلب الجهات الكبيرة |
| المهام | **Queue** (تقارير PDF/إشعارات/تحليلات) | فصل الأحمال |
| المراقبة | تتبّع أداء وأمن + سجل تدقيق Append-only | حوكمة وامتثال |

## المبادئ الحاكمة في المعمار
- **P4 — ثبات النتائج:** `assessments.model_snapshot` + `scoring_version` مجمّدان وقت الإطلاق؛ تعديل القالب لاحقاً لا يمسّ نتائج سابقة.
- **P2 — الأدلة قبل الاعتماد:** لا تدخل `final_score` في `scores` إلا بعد `status='approved'` من مراجع.
- **P6 — الأمن بالتصميم:** RLS لكل مستأجر، تشفير عند النقل والتخزين، `audit_logs` بلا UPDATE/DELETE، جاهزية **PDPL** السعودي.
- **P7 — الذكاء الاصطناعي مساعد:** خدمة اقتراح منفصلة تُرجع (اقتراح + مصدر + ثقة)، تُسجَّل في التدقيق، ولا تعتمد درجة دون مراجع بشري، وقابلة للتعطيل لكل مؤسسة.

## خريطة الترحيل من v1
| مكوّن v1 (JS static) | مقابله في v2 |
|---|---|
| `store.js` (localStorage) | NestJS services + PostgreSQL + RLS |
| `model.js` (Snapshot في الكود) | `template_versions.body` + تجميد في `assessments.model_snapshot` |
| `scoring.js` | خدمة احتساب مستقلة بإصداراتها تكتب في `scores`/`findings` |
| `roles.js` | حراس NestJS (Guards) + `memberships.role` |
| طباعة المتصفح | خدمة PDF في Queue (Playwright/Server-side) |

## أولويات v2 (بالترتيب)
1. المصادقة + المؤسسات + الأدوار (Guards) + RLS.
2. القوالب وإصداراتها + إطلاق تقييم مع Snapshot.
3. الإجابات + رفع الأدلة المشفّر + الحفظ التلقائي.
4. محرك الاحتساب كخدمة + لوحة النتائج.
5. خطة التحسين + المقارنة الزمنية + خدمة PDF.
6. تصليب الأمن: MFA/SSO، اختبار اختراق، WCAG 2.2 AA، فصل العملاء.
