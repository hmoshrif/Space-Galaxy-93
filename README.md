# نضج — منصة إدارة النضج والتحسين المؤسسي

منصة عربية تحوّل تقييم النضج المؤسسي من **مجرد درجة 1–5** إلى **دورة تحسين كاملة**:

> قياس النضج ← إثبات بالأدلة ← اكتشاف الفجوات ← بناء خطة تحسين ← متابعة التنفيذ ← إعادة القياس

هذه هي **النسخة الأولى (v1 MVP)** المنفّذة وفق [أمر الاستدعاء الرئيسي](docs/master-prompt.md) وبروتوكول التنفيذ المرحلي.

## 🚀 التشغيل
لا يتطلب خطوة بناء أو حزم:
```bash
cd app && python3 -m http.server 8099
# افتح: http://localhost:8099/index.html  ثم اضغط «تجربة عرض جاهزة ▶»
```

## 🗂️ البنية
```
app/
  index.html            # هيكل RTL عربي
  assets/styles.css     # نظام تصميم (Design Tokens · WCAG · وضع ليلي)
  js/
    model.js            # نموذج النضج — مصدر واحد للحقيقة
    scoring.js          # محرك الاحتساب الشفاف (scoring-v1)
    store.js            # الحالة + تجميد Snapshot + سجل تدقيق
    charts.js           # رسوم SVG (heatmap/radar/impact-effort)
    seed.js             # بيانات عرض تجريبية جاهزة
    ui.js               # التوجيه + الشاشات الست
docs/                   # وثيقة المنتج · نموذج النضج · أمر الاستدعاء
```

## 🔒 قرارات معمارية حاكمة
- **P4 — ثبات النتائج:** يُجمَّد Snapshot من النموذج + إصدار المعادلة عند إطلاق كل تقييم.
- **P2 — قائم على الأدلة:** لا تدخل درجة في الحساب إلا بعد اعتماد المراجع.
- **P3 — الشفافية:** أوزان الأنواع ومنطق الاحتساب معروضة للمستخدم.

## 🛣️ مسار الإنتاج (v2)
