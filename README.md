# مكعب أنظمة الابتكار — Innovation Systems Cube

موقع إلكتروني احترافي تفاعلي يعرض إطارًا تحليليًا للابتكار في **ثلاثة أبعاد متعامدة**:

| المحور | النظام | الاختصار | السؤال |
|:------:|--------|:--------:|--------|
| **X** | النظام الوطني للابتكار | NIS | أين يحدث؟ |
| **Y** | النظام القطاعي للابتكار | SSI | في أي قطاع؟ |
| **Z** | النظام التكنولوجي للابتكار | TIS | حول أي تقنية؟ |

كل نشاط ابتكاري يُمثَّل كـ **إحداثيٍّ دقيق** عند تقاطع هذه الأنظمة الثلاثة، ويُعرض على مكعب ثلاثي الأبعاد قابل للتدوير والاستكشاف.

## المميزات

- 🧊 **مكعب تفاعلي ثلاثي الأبعاد** مبني بـ CSS 3D Transforms خالصة (بدون مكتبات خارجية).
- 🖱️ تدوير بالسحب (ماوس/لمس)، تدوير تلقائي، وإعادة ضبط الزاوية.
- 📍 أمثلة تطبيقية حقيقية تُحرّك المؤشّر إلى خليّته مع خطوط استدلال (guides).
- 📊 شرح **المحاور الثلاثة** و**الوظائف السبع** للنظام التكنولوجي.
- 🌐 تصميم عربي (RTL) متجاوب بالكامل مع وضع داكن احترافي.
- ✨ شريط تقدّم القراءة، إبراز القسم النشط، زر العودة للأعلى، وتأثيرات ظهور عند التمرير.
- ♿ يحترم `prefers-reduced-motion` ويدعم التنقّل بلوحة المفاتيح (`focus-visible`).

## التشغيل محليًا

الموقع ثابت بالكامل (static) ولا يحتاج بناءً أو اعتماديات.

- **الأبسط:** افتح `site-standalone.html` مباشرة في المتصفح (ملف واحد، يعمل بالكامل).
- **النسخة متعددة الملفات:** افتح `index.html` عبر خادم محلي (للحفاظ على المسارات النسبية):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر (GitHub Pages)

الموقع جاهز للنشر مباشرةً على GitHub Pages من جذر الفرع — الصفحة الرئيسية هي `index.html`.

## التخصيص

- **الفئات**: عدّل المصفوفات `NIS` / `SSI` / `TIS` في `assets/js/cube.js`.
- **الأمثلة**: أضف صفوفًا إلى `EX` بالصيغة `[nisIdx, ssiIdx, tisIdx, "العنوان", "السرد"]`.
- **الألوان**: متغيّرات `--cyan` / `--amber` / `--violet` في `:root` بملف `style.css`.
